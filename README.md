# 교실 환기 알림판

교실 앞 화면에서 상태와 환기 안내를 보여 주고, 선생님 보기에서 날짜별 알림과 행동을 확인하는 1교실용 웹앱입니다.

## 로컬 실행과 데모

Node.js 24와 npm이 필요합니다.

```bash
npm ci
npm run dev
```

터미널에 표시된 주소를 열고 **데모 시작**을 누릅니다. 센서, 계정, API 키 없이 약 7초 후까지 **측정 중 → 괜찮아요 → 곧 환기가 필요해요**가 차례로 표시됩니다. 환기 안내가 나오면 재생이 자동으로 멈춰 행동을 기록할 수 있습니다. **창문 열었어요** 또는 **공기청정기 켰어요**를 누른 뒤 **선생님 보기**에서 `데모 · 가상 기록`의 알림과 `완료`를 확인합니다. 아무 행동 없이 **계속 재생**하면 재생 시각의 제한을 넘겨 `놓침`을 확인할 수 있습니다.

`npm test`는 판정 경계, CSV 열 대응, 센서 파서, 등급 유효성, 기기 승인과 가상 기록 차단을 검사합니다. `npm run build`는 배포용 빌드입니다.

## 기본 교실 현황과 수동 행동 기록

앱을 열면 센서나 수업 타이머 없이도 마지막 창문 열기 시각과 지난 시간, 유효한 바깥 미세먼지 등급과 관측 시각을 보여 줍니다. 온도와 습도는 센서 연결을 통한 실측이 있을 때만 현황에 표시합니다. 데모·CSV는 직접 시작한 재생 화면에서만 표시됩니다.

알림이 없어도 현황에서 **창문 열었어요** 또는 **공기청정기 켰어요**를 눌러 이미 한 행동을 기록할 수 있습니다. 이 기록은 **선생님 보기 → 수동 · 이 브라우저**에서만 확인할 수 있고 알림 응답 건수에 포함되지 않습니다.

## 선생님 보기 잠금

배포 환경에 공통 PIN을 비밀 변수 `TEACHER_PIN`으로 설정합니다. 로컬에서는 `.env.local` 같은 비공개 환경에 설정합니다. `VITE_` 접두사를 붙이지 마세요. 어느 브라우저에서든 같은 PIN을 입력하며 서버가 검증합니다. **선생님 보기**와 **교사용 CO₂ 모니터**는 각각 현재 화면에서만 최대 30분 동안 잠금이 해제되며, **잠그기**, 화면 이동, 새로고침 시 다시 잠깁니다. 행동 기록은 브라우저에만 남고 암호화되지는 않습니다. 교실 현황과 행동 버튼은 PIN 없이 사용할 수 있습니다.

## 센서 없이 쓰는 수업 타이머

**타이머 모드 → 알림 간격 → 수업 시작**을 선택하세요. 기본 간격은 30분이고, 1분 테스트용 옵션도 있습니다. 시간이 되면 **환기를 확인할 시간이에요**가 표시됩니다. 기존 에어코리아 관측 등급을 사용하지만 값이 없거나 오래됐을 때는 창문 열기를 안내하지 않습니다. 센서나 예측 결과는 사용하지 않습니다.

알림에서 **창문 열었어요**와 **공기청정기 켰어요**를 서로 다른 행동으로 저장합니다. 마지막 창문 환기 시각에는 이 브라우저에 기록된 실제 창문 열기만 반영합니다. 같은 탭에서 선생님 보기로 이동하거나 새로고침해도 저장된 알림 예정 시각을 기준으로 타이머가 이어집니다. **수업 종료**를 누르면 예정 알림과 화면에 떠 있는 알림을 멈추고 이미 남긴 기록은 유지합니다. 수업 타이머 상태는 탭별로 보관하며, 새 탭에서는 자동으로 시작하지 않습니다. 타이머·센서·수동 행동 기록은 그 행동을 기록한 브라우저에서만 확인할 수 있습니다.

## CSV 업로드와 재생

**CSV 재생 → 예시 CSV 다운로드** 또는 [public/example.csv](public/example.csv)를 사용하세요. UTF-8 쉼표 구분 파일(머리글 포함, 최대 2MB 및 측정값 20,000개)을 지원합니다.

```csv
timestamp,humidity,temperature,noise
2026-11-19T09:00:00+09:00,53.2,23.40,37
2026-11-19T09:20:00+09:00,50.0,23.44,41
2026-11-19T09:25:00+09:00,48.4,23.78,
```

- 열 순서와 머리글 이름은 자유입니다. 업로드 후 **측정 시각, 습도, 온도, 소음** 항목에 각 열을 연결하세요. `noise`는 생략하거나 비워도 됩니다.
- 시각은 ISO 8601 형식입니다. 시간대가 없는 값은 한국 시각으로 해석하고 기록은 시간순으로 정렬합니다. 시각이 중복된 기록과 결측값은 예측에 쓰지 않습니다. 30초 간격으로 연속된 41개가 모일 때까지 `측정 중`으로 표시합니다. 위의 3행은 형식 예시입니다. 표시 및 날짜 집계는 한국 시각입니다.
- 1·60·240배속과 일시 정지를 지원합니다. 배속과 관계없이 20분 관측, 10분 행동 마감, 같은 안내의 20분 재알림 제한은 CSV의 시각으로 계산합니다. 마지막 측정 뒤 마감까지 진행하고 끝납니다. 수동 종료 시 재생 시각은 멈추며, 아직 마감 전인 알림은 그 시각 기준으로 `대기 중`입니다.
- 현재 에어코리아 측정값을 과거의 CSV 기록에 적용하지 않습니다. CSV에는 재생 시각에 해당하는 미세먼지 관측값이 없으므로 `바깥 미세먼지 확인 필요`를 표시합니다.

## USB 마이크로비트

데스크톱 Chrome에서 HTTPS 배포 주소 또는 로컬 개발 주소를 **탭에서 직접** 열고 **센서 연결**로 USB 포트를 선택합니다. 브라우저에 따라 임베드된 미리보기에서 포트 권한이 차단될 수 있습니다.

지원하는 예시 출력은 **115200 baud, UTF-8, 한 줄에 JSON 하나**입니다. 앱은 교실 컴퓨터 시계의 30초 수신 구간마다 첫 유효 샘플 하나를 기록합니다. 안정적인 샘플링을 위해 장치는 30초보다 자주 전송하는 것이 좋습니다. 빈 구간은 채우지 않고, 수신한 유효값만 표시합니다. 소음은 판정에 사용하지 않습니다.

```json
{"humidity":48.2,"temperature":23.25,"noise":41}
{"humidity":47.9,"temperature":23.32}
```

온도는 °C, 습도는 상대 습도 %를 사용합니다. 소음은 선택이며 값의 단위와 보정은 장치 설정을 따릅니다. 펌웨어 출력 형식이 바뀌면 `src/lib/vent-input.ts`의 `parseSerialLine()`에서 맞춥니다. 수신 구간이 비어 연속성이 끊기면 새 유효 기록이 41개 모일 때까지 `측정 중`으로 돌아갑니다.

## 환기 예측 모델과 바깥 미세먼지

- `src/lib/ventilation.ts`는 최근 **30초 간격의 유효 기록 41개(20분)**를 확인하고 `temperature`를 `temp`로 넘겨 첨부 모델 원본인 `src/lib/predict.js`를 실행합니다. 문턱값은 **0.7**이며 `0`은 `괜찮아요`, `1`은 환기 필요, 기록 부족은 `측정 중`으로 표시합니다. 보간은 하지 않습니다. 모델 일치 검증과 별개로 실제 교실에서의 예측 성능은 아직 검증하지 않았습니다.
- 한 알림이 열려 있는 동안 중복 생성하지 않습니다. 행동 없는 알림은 10분 경과 후 `놓침`으로 표시하고 같은 조건이 이어진다고 매 측정마다 다시 생성하지 않습니다. 행동이 기록되면 같은 안내의 재알림을 20분간 제한합니다. `완료`는 행동을 제때 기록했다는 의미이며 실제 환기 여부는 확인하지 않습니다.
- 바깥 미세먼지는 [경상북도 실시간 대기정보](https://www.gb.go.kr/Main/air/page.do?mnu_uid=16628)의 문경시 측정소 공개 표에서 PM10 농도, 시간별 등급, 관측 시각을 자동 조회합니다. 문경시 조회에 인증키가 필요하지 않습니다. 유효한 결과는 최대 5분간 캐시하고, 점검·누락 또는 관측 시각이 2시간 이상 지나면 등급을 사용하지 않습니다. `좋음/보통`은 창문 열기, `나쁨/매우 나쁨`은 공기청정기를 안내합니다. 등급이 없거나 현재 등급이 기존 안내와 맞지 않을 경우 자동으로 창문을 권장하지 않습니다. 데모의 미세먼지 값은 화면에 가상으로 표시됩니다.

## 시범 교실 CO₂ 조회

- **교사용 CO₂ 모니터**에서 학생 링크를 복사하고, 기본 경고 기준(1,000 ppm 초과가 5분 연속)을 바꿀 수 있습니다. 학생 링크 `/classroom/pilot`에는 최신 값, 측정 시각, 상태만 표시됩니다. 새 측정값은 자동으로 갱신되고, 90초 넘게 값이 들어오지 않으면 **측정 중단**이 표시됩니다.
- **기기 등록**으로 측정 기기 한 대의 전송 키를 발급합니다. 키는 등록 직후 한 번만 표시되며, 등록을 해제하면 이전 키는 쓸 수 없습니다. 키는 측정 기기에만 보관하고 학생 링크나 소스에 넣지 마세요.
- 측정 기기는 HTTPS `POST /api/classrooms/pilot/device/reading`에 `Authorization: Bearer <기기 전송 키>`와 `Content-Type: application/json`을 보내야 합니다. 본문의 `ppm`은 정수 CO₂ 값(250~10,000), `measuredAt`은 UTC Unix 밀리초입니다. 약 30초마다 한 번씩 보내고, 기기의 시계를 맞춰 주세요. 정상적으로 연결을 닫을 때는 같은 인증으로 `POST /api/classrooms/pilot/device/disconnect`를 보냅니다. 실제 센서나 기기 펌웨어는 포함되어 있지 않습니다.
- **CO₂ 데모**는 기본 경고에 필요한 연속 초과, 복구, 연결 끊김을 네트워크 전송 없이 보여 줍니다. 실측값과 함께 표시하거나 실측 측정 이력에 저장하지 않습니다.
- 과거 행동 공유는 중단했습니다. 이전에 저장된 공유 데이터는 삭제하지 않았고, 앱은 더 이상 해당 서버 기록을 조회하거나 새 행동을 전송하지 않습니다.

CO₂ 미리보기는 배포 데이터와 별도로 동작합니다. BAZE에 게시할 때 학생이 로그인 없이 들어오려면 공개 범위를 전체 공개로 유지해야 합니다. 별도 로그인이나 학생 이름 수집은 없습니다.

## GitHub 저장소를 Vercel에 연결하는 경우

1. Supabase SQL Editor에서 [시범 교실용 SQL](supabase/migrations/20261122000000_classroom_live.sql)만 실행합니다. 새 비공개 저장 공간을 만들며, 과거 행동 기록은 옮기거나 바꾸지 않습니다.
2. GitHub 저장소를 Vercel에서 **Import**합니다. 프레임워크는 **Vite**, Node.js는 **24.x**를 사용합니다. 빌드와 학생·교사 링크 설정은 저장소에 포함되어 있습니다.
3. Vercel의 **Environment Variables**에 비밀값 `CLASSROOM_DATABASE_URL`(Supabase **Connect → Transaction pooler** 연결 주소, SQL을 실행한 `postgres` 계정, TLS 인증 가능한 연결)과 `TEACHER_PIN`(공유하지 않는 충분히 긴 교사용 PIN)을 등록합니다. 채팅·GitHub·`VITE_` 변수에 비밀값을 넣지 마세요. 문경시 미세먼지는 키가 필요 없어요. Vercel의 시스템 환경 변수를 노출하면 공유 링크 미리보기에 Vercel 주소가 적용됩니다.
4. 배포한 뒤 로그인하지 않은 창에서 학생 화면과 문경시 미세먼지를 확인하고, 교사용 CO₂ 화면에서 기기를 새로 등록합니다. 학생이 Vercel 계정 없이 열려면 공유할 배포 주소에 Vercel Deployment Protection이 걸려 있지 않아야 합니다.

Vercel과 BAZE의 시범 교실 등록·CO₂ 데이터는 별개입니다. Vercel 학생 링크를 쓰려면 기기에도 해당 Vercel 주소와 새 전송 키를 넣어야 합니다. 교실 행동 기록은 계속 기록한 브라우저 안에만 남습니다.
